# Third-party content and models

This project uses IndianWeb2 as its article source. Article text, original HTML, images, scripts and publisher marks remain the property of their respective rights holders. Source URLs and original fetch metadata accompany the five assignment sample pairs. They are reproducibility fixtures, not material authored by this project's developer, and are not relicensed as project code.

The full corpus, model weights, package environment, caches and vector database are excluded from Git. Five samples are kept byte-identical for the assignment's raw-HTML requirement; opening raw HTML in a browser can load publisher resources. Inspect it as text when checking original bytes. Model weights download from public upstream repositories during setup and retain their upstream terms.

Sources and upstream projects:

- [IndianWeb2](https://www.indianweb2.com/), [editorial policies](https://www.indianweb2.com/p/editorial-policies.html), [privacy policy](https://www.indianweb2.com/p/privacy-policy.html).
- [GLiNER small-v2.1](https://huggingface.co/urchade/gliner_small-v2.1) and [GLiNER](https://github.com/urchade/GLiNER).
- [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2).
- [spaCy models](https://github.com/explosion/spacy-models), [Chroma](https://github.com/chroma-core/chroma), [Trafilatura](https://github.com/adbar/trafilatura).

The source-policy review did not establish an affirmative blanket licence to redistribute publisher pages. Public accessibility and robots allowance are not represented as such a licence. No publisher permission has been obtained, and this notice itself does not grant permission. This fact remains recorded separately from technical sample correctness and repository visibility.
